
# Developer MASTERMIND

A private, offline-first study PWA.

## Current features

- Responsive dashboard
- Light, dark and system theme
- Local notes using IndexedDB
- Autosave
- Search note titles and content
- Basic service worker caching
- PWA manifest
- English and Bangla text input

## Planned modules

- Bengali and English OCR
- Photo library and attachments
- Photo-to-PDF and PDF tools
- PDF sharing
- Study planner and reminders
- Pomodoro timer
- Flashcards and revision tracker
- Study analytics
- Backup and restore
- PIN and supported biometric authentication
- Additional fonts and accessibility settings

## Privacy

Notes in the current version are stored in the browser's
IndexedDB database on this device.

GitHub hosts the source code. It does not automatically
receive notes stored by the app.

Browser storage can be cleared by the user, browser,
or operating system. Export and restore features should
be implemented before storing important study material.

## Hosting

Publish the repository with GitHub Pages using HTTPS.

After publishing, open the site once while online so
the initial application files can be cached.

## Development

Edit the files, commit the changes and push them to GitHub.
Test the deployed site on the target Android browser.
